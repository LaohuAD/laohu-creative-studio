## English

This directory contains six non-user layout previews. Each preview preserves the complete components, order, and theme styling of its corresponding `docs-gallery/` layout in the Laohu creative skills repository; only the original gallery article text is replaced with original copy about Laohu. A separately labeled format demo remains to show headings, body text, quotes, lists, tables, and image captions. Original gallery articles, author experiences, signatures, and subscription prompts are not shown as preview copy. These files demonstrate distinct layouts; they are not user articles, a bundled layout engine, or final variants ready for submission. Source and license notices remain in the HTML comments, this NOTICE, and `LICENSE`.
