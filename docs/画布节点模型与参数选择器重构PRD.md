# 画布节点模型选择器与参数面板重构 PRD

## 0. 文档信息

- 版本：V1
- 模块：无限画布 · 生成节点（文本 / 图片 / 视频 / 音频 / 音乐）
- 涉及文件：`static/js/smart-canvas.js`、`static/css/smart-canvas.css`、`model_capabilities.py`（数据层，本次不改）、`tests/test_workbench_model_picker.py`、`tests/test_studio_model_picker.py`
- 状态：需求已确认，待实现验收

---

## 1. 版本概述

本次改造针对画布节点上的两块交互：**模型选择器**和**参数配置面板**。

- 模型选择器：把选择顺序统一为「模型 → 平台 → 运行模式」，并让最后一段「运行模式」支持悬停预览真实模型 ID、选中即确定。
- 参数面板：把常用参数直接铺在面板上，冷门高级参数收进齿轮，参数区顶部暴露真实模型 ID。

目标是让选择更符合用户直觉、常用调节一眼可见、同时给懂行的用户暴露底层真实模型标识。

---

## 2. 需求背景

### 2.1 表层需求（用户原始表达）

用户在画布节点上看到三个下拉/选择项和一个装参数的齿轮，提出：

1. 选择项现在分「选择模型、运行模式、平台」三块，名称不直观，希望重新命名。
2. 选择顺序希望改成：先选模型，再选平台，最后选运行模式。
3. 希望把同一个模型（如 Seedance）在不同平台、不同版本下的条目归类到一起，只在最后的「运行模式」上做区分。
4. 参数现在全塞在一个齿轮里，希望常用参数（时长、分辨率、比例等）像参考图那样直接铺开显示，冷门的高级参数才收进齿轮。
5. 选中结果用「小圆点分隔的小长条」呈现（如 `模型 · 平台 · 运行模式`、`720p · 5秒 · 是…`）。
6. 菜单里给用户看得懂的名字，但要在参数面板最上面那个空框里暴露真实的 API 模型名（一串英文）。
7. 交互上：模型、平台点击才确定；运行模式（最后一段）选中即确定并收起面板；在收起前，鼠标悬停到某个运行模式时，顶部实时显示它对应的真实模型 ID。
8. 整体布局排得紧凑、对仗工整、信息完整。

### 2.2 真正想达成的目标（根本目的）

- **让用户按直觉选模型**：先认品牌/模型，再挑调用渠道（平台），最后定运行模式，符合人的心智顺序。
- **降低选择成本**：常用参数一眼可见可调，冷门参数不干扰主流程。
- **既友好又透明**：普通用户看得懂的名称降低门槛，暴露真实模型 ID 让懂行的用户能精确判断实际调用的是哪个模型。

### 2.3 关键现状事实（实现地基）

- 系统底层已是「能力驱动」的统一数据模型，模型天然带五层信息：**平台(provider) → 能力大类(node_type) → 系列/家族(family) → 变体/运行模式(variant) → 具体模型(model_id)**。
- 「同一模型跨平台」已有底层支持：存在「逻辑家族」概念（如"即梦视频"），其下挂着来自多个平台的变体。因此「模型 → 平台 → 运行模式」的聚合不需要从零构建，主要是调整前端三段的顺序、过滤和交互。
- 参数每项已带 `level` 字段（`required` / `optional` / `advanced`），因此「常用 vs 高级」分层的数据现成。
- 现状短板：参数当前全部塞进齿轮弹层；`native1080p` 等选项无中文映射会显示英文。

## 4. 命名规范（内部键 → 用户可感知名）

| 现在的概念 | 内部键 | 面向用户的新叫法 | 说明 |
|---|---|---|---|
| family（家族） | `family_id` | **模型** | 用户认知的"选哪个模型"，如 Seedance、Kling |
| provider（供应商） | `provider_id` | **平台** | 调用渠道，如 即梦、火山、RunningHub |
| variant（变体） | `variant_key` | **运行模式** | 文生视频 / 图生视频 / 首尾帧 / 多图参考 等 + 版本档次 |
| model_id | `model_id` | 真实模型名（仅顶栏暴露） | 如 `seedance-2.5-i2v`，给懂行用户看 |

术语统一约定：**平台 = provider = 厂商，模型 = family = 系列，运行模式 = variant = 模式**。

## 6. 功能需求说明

### 6.1 模型选择器（三段级联）

**弹层三段顺序**：模型(1) → 平台(2) → 运行模式(3)。

- **模型段**：展示当前输入条件下所有可用模型（逻辑家族）。
- **平台段**：展示所选模型在全部已启用平台上的可选渠道；即使只有一个平台也始终显示。RunningHub 按启用区域拆为 `RunningHub · CN` / `RunningHub · AI` 两条。
- **运行模式段**：只展示当前所选平台真实提供的运行模式，避免出现"选了平台却无法运行该模式"。每个运行模式项带能力徽章（首尾帧 / 多图参考 / 文生视频 等，最多 4 个）。

**选中结果 pill**：显示 `模型 · 平台 · 运行模式`，中间用 `·` 分隔；`title` 悬浮提示追加真实 `model_id`。

### 6.2 交互规则

| 段 | 点击行为 | hover 行为 |
|---|---|---|
| 模型 | 点击确定，重算候选并级联刷新下游；弹层保持打开 | 常规悬停高亮，不改顶栏 |
| 平台 | 点击确定，刷新运行模式候选；弹层保持打开 | 常规悬停高亮，不改顶栏 |
| 运行模式 | 选中即确定，写入设置并收起整个参数选择弹层 | 顶栏真实模型 ID 框实时切换为该运行模式对应的 `model_id`，移开还原为已选值 |

- 保持打开/自动恢复由现有 `openControlState` / `restoreOpenControl` 机制承接：任何点击后重渲染会自动恢复同一弹层的打开态；运行模式点击时主动移除 pinned，使弹层收起。
- 所有参数打开即有默认选中值（来自 profile 的 `spec.default`）。

### 6.3 参数面板分层

- **常用参数**（非 `advanced`：分辨率、时长、画幅/比例、生成音频、画质等）：直接铺在参数面板网格里，用内联 pill 控件展示，样式对齐参考图（分段按钮、滑块、比例图标网格）。
- **高级参数**（`level === 'advanced'`：seed、penalty、reasoning_effort 等）：收进右侧齿轮弹层。若某模型无高级参数，齿轮不显示。
- **排序**：常用参数按 分辨率 → 画质 → 时长 → 画幅 → 其余 的优先级排列。

### 6.4 真实模型 ID 暴露

- 参数面板顶栏右侧显示当前 profile 的 `model_id`（`renderCapabilityModelName`）。
- 运行模式段 hover 时，该文本实时替换为悬停项对应的 `model_id` 并加高亮态（`is-previewing`），移开恢复。

### 6.5 底部摘要小长条

- 参数确定/面板收起后，节点底部条以 `·` 分隔展示当前常用参数值（如 `720p · 5秒 · 是…`）。

### 6.6 本地化补全

- 补 `native1080p → 原生1080p`（及英文 `Native 1080p`）等分辨率选项映射，消除残留英文。

## 7. 业务流程

用户打开生成节点参数面板：

1. 面板顶栏显示当前真实模型 ID；常用参数已铺开并带默认值；有高级参数时显示齿轮。
2. 点击模型选择器 pill，展开三段弹层。
3. 在「模型」段点击目标模型 → 平台段刷新为该模型可用平台，弹层保持打开。
4. 在「平台」段点击目标平台 → 运行模式段刷新为该平台可用模式，弹层保持打开。
5. 在「运行模式」段移动鼠标预览：顶栏实时显示各模式对应真实模型 ID。
6. 点击目标运行模式 → 确定选择，弹层收起，参数面板刷新为该模型的常用参数。
7. 调整常用参数（面板直接操作）或点齿轮调整高级参数。
8. 底部条以点分隔小长条呈现当前选择与参数摘要。

---

## 8. 业务规则

- 运行模式段仅展示当前平台真实支持的模式；平台段展示模型的全部可用平台。
- 模型/平台切换必须显式点击才生效；运行模式选中即生效并收起。
- hover 预览只读、不写入设置、不触发持久化，移开即还原。
- 参数分层依据后端 `level` 字段，不在前端硬编码哪些参数属于高级。
- 已保存节点的既有模型选择与参数值在改版后保持不丢失（向后兼容）。
- RunningHub 区域选择写入 `settings.rhRegion`。

## 10. 异常情况与边界条件

- 当前输入下无可用选项：段内显示"当前输入下没有可用选项"占位。
- 模型仅有单一平台/单一运行模式：段仍显示，直接呈现唯一项。
- 模型无高级参数：齿轮不渲染。
- 运行模式项缺少 `model_id`：hover 不触发预览切换。
- 搜索无匹配：显示"没有匹配"提示。
- RunningHub 区域未启用：该区域条目不出现。

## 11. 验收标准

- 打开任一生成节点，模型选择器三段顺序为「模型 → 平台 → 运行模式」，五类节点一致。
- 选中某模型后，平台段展示该模型全部可用平台；切换平台后运行模式段随之刷新为该平台支持的模式。
- 悬停运行模式选项时，顶栏真实模型 ID 框实时显示对应 `model_id` 并高亮，移开后恢复为已选值，全程不写库、不卡顿。
- 点击模型 / 平台不关闭弹层并正确级联；点击运行模式后立即确定并收起面板。
- 参数面板：分辨率 / 时长 / 比例 / 生成音频 / 画质等常用参数直接铺开可调，样式对齐参考图；`seed` 等高级参数收在齿轮内；无高级参数时齿轮不显示。
- 所有参数打开即有默认选中值；确定后底部条显示 `·` 分隔的紧凑摘要。
- `native1080p` 等选项显示为中文，无残留英文。
- 既有已保存节点的模型选择与参数在改版后不丢失。
- 相关测试（`test_workbench_model_picker.py`、`test_studio_model_picker.py`）契约同步更新并通过。
